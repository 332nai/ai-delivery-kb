# Characters and Worldbuilding

28 prompts for character creation, world design, and setting details.

## Character creation

1. Create a character with [profession], a contradiction, and a wound.
2. Generate 3 character flaws that drive [protagonist]'s story arc.
3. Write a 1-page character sheet for [name]: backstory, goal, fear, voice.
4. Generate a believable origin story for [character archetype].
5. Suggest 5 small habits that show who [character] really is.
6. Build a moral framework for [character] including red lines.
7. Generate an antagonist who's a darker version of [protagonist's value].
8. Suggest a name and one-line description for 5 supporting characters.

## Relationships and dynamics

9. Build the relationship history between [A] and [B] in 5 beats.
10. Generate a power dynamic between [characters] that shifts over time.
11. Write a 1-line description of how each character sees [protagonist].
12. Suggest a foil character for [protagonist] highlighting [trait].
13. Map the love triangle / rivalry between [3 characters].
14. Generate a mentor figure whose advice is partially wrong.
15. Write a 'first impression vs reality' contrast for [character].

## Worldbuilding

16. Design a [genre] setting where [unique rule] shapes daily life.
17. Generate 5 details about everyday life in [world] that show its rules.
18. Build a magic/tech system with hard limits and costs for [world].
19. Design a political structure for [setting] with 3 factions in tension.
20. Generate the economy of [world]: what's scarce, what's currency, who profits.
21. Write a 100-word in-world document (law/poem/letter) from [setting].
22. Design a religion / belief system relevant to [story conflict].

## Settings and atmosphere

23. Describe [place] through 3 senses, evoking [feeling].
24. Generate sensory details that make [setting] feel lived-in.
25. Design a single location where [story conflict] could play out fully.
26. Write atmospheric details for [time of day] in [setting].
27. Generate weather and seasonal change that mirror [story mood].
28. Describe [object] in a way that hints at its history.

**Total prompts: 28**

# 角色与世界观

28 条 prompt: 角色创建、世界设计、背景细节。

## 角色创建

1. 创造一个有 [职业]、一个矛盾、一道伤口的角色。
2. 为 [主角] 故事弧线生成 3 个驱动它的性格缺陷。
3. 为 [姓名] 写一份 1 页人物表: 背景、目标、恐惧、声音。
4. 为 [角色原型] 生成一个可信的起源故事。
5. 建议 5 个能透露 [角色] 真实自我的小习惯。
6. 为 [角色] 构建道德框架,含红线。
7. 生成一个反派,是 [主角价值观] 的黑暗版。
8. 为 5 个配角建议名字和一句话描述。

## 关系与动态

9. 用 5 个节拍构建 [A] 和 [B] 的关系史。
10. 为 [角色们] 生成一个随时间转移的权力动态。
11. 为每个角色写一句话,说明他们怎么看 [主角]。
12. 为 [主角] 建议一个突出 [特质] 的对照角色。
13. 画出 [3 个角色] 之间的三角恋/对立关系。
14. 生成一个建议部分错误的导师角色。
15. 为 [角色] 写一段'第一印象 vs 真实'的对比。

## 世界观

16. 设计一个 [体裁] 设定,[独特规则] 塑造日常生活。
17. 为 [世界] 生成 5 个能展示其规则的日常生活细节。
18. 为 [世界] 构建一个有硬性限制和代价的魔法/科技系统。
19. 为 [设定] 设计一个 3 派紧张的政治结构。
20. 为 [世界] 生成经济: 什么稀缺、什么是货币、谁获利。
21. 为 [设定] 写一份 100 字的世界内文档 (法律/诗/信)。
22. 为 [故事冲突] 设计一套相关的宗教/信仰体系。

## 场景与氛围

23. 通过 3 种感官描写 [地点],营造 [感觉]。
24. 为 [设定] 生成让它显得有人住过的感官细节。
25. 设计一个能让 [故事冲突] 完整展开的单一场景。
26. 为 [设定] 的 [时段] 写氛围细节。
27. 生成与 [故事氛围] 相呼应的天气和季节变化。
28. 用暗示其历史的方式描写 [物品]。

**共 28 条 prompt**
