# Memory and Notes

28 prompts for memory techniques, mnemonics, and note-taking systems.

## Mnemonics

1. Create a mnemonic for remembering [list of items].
2. Build a memory palace route through [familiar place] for [N facts].
3. Generate an acronym to remember [steps/concepts].
4. Convert [abstract list] into a vivid story I can remember.
5. Create a rhyme for [tricky fact].
6. Design a visual mnemonic for [concept] linking it to [vivid image].
7. Generate a peg system for remembering an ordered list of [N] items.

## Note-taking systems

8. Convert this lecture into Cornell notes: [paste].
9. Generate a Zettelkasten-style atomic note from [idea].
10. Build a structured note from [source] using PARA categories.
11. Convert this textbook chapter into a 1-page summary with diagrams: [paste].
12. Generate a 'progressive summarization' (4 layers) of [text].
13. Design a daily note template for [type of work] with these sections.
14. Convert my messy notes into a flow diagram: [paste].

## Linking and synthesis

15. Connect [new idea] to 3 things I already know about [related field].
16. Find non-obvious connections between [topic A] and [topic B].
17. Build a concept map for [topic] showing relationships.
18. Synthesize [N notes] into a single insight: [paste].
19. Generate 5 questions linking [concept] to other concepts in [field].
20. Suggest what to read next given my notes on [topic]: [paste].
21. Identify the 'theme' running through these notes: [paste].

## Long-term retention

22. Design a spaced repetition schedule for these flashcards: [paste].
23. Suggest the optimal review interval after I've recalled [card] correctly.
24. Build a 'leech' identifier for cards I keep getting wrong: [paste].
25. Convert these cards from recognition to recall format: [paste].
26. Suggest how to combine 5 related facts into one stronger card.
27. Identify which of these cards are too hard and should be split: [paste].
28. Build a yearly review schedule to keep [N] cards alive.

# 记忆与笔记

28 条 prompt: 记忆术、助记法、笔记系统。

## 助记法

1. 为记住 [清单] 创建一个助记符。
2. 用 [熟悉地点] 为 [N 个事实] 构建一条记忆宫殿路径。
3. 为 [步骤/概念] 生成首字母缩略词。
4. 把 [抽象清单] 转成我能记住的生动故事。
5. 为 [难记的事实] 创建一句押韵。
6. 为 [概念] 设计视觉助记符,链接到 [生动图像]。
7. 用挂钩法为 [N] 项有序清单生成助记。

## 笔记系统

8. 把这段讲座改成康奈尔笔记: [粘贴]。
9. 为 [想法] 生成一条 Zettelkasten 风格的原子笔记。
10. 用 PARA 分类法为 [来源] 构建结构化笔记。
11. 把这章教材转成带示意图的 1 页摘要: [粘贴]。
12. 为 [文本] 生成 4 层渐进式摘要。
13. 为 [工作类型] 设计含这些章节的每日笔记模板。
14. 把我乱七八糟的笔记改成流程图: [粘贴]。

## 关联与综合

15. 把 [新想法] 与 [相关领域] 里我已知的 3 件事关联起来。
16. 找出 [话题 A] 和 [话题 B] 之间不明显的联系。
17. 为 [话题] 构建展示关系的概念地图。
18. 把 [N 条笔记] 综合成一条洞见: [粘贴]。
19. 生成 5 个把 [概念] 与 [领域] 其他概念链接的问题。
20. 基于我 [话题] 的笔记,建议接下来读什么: [粘贴]。
21. 识别这些笔记里贯穿的'主题': [粘贴]。

## 长期保留

22. 为这些抽认卡设计间隔重复计划: [粘贴]。
23. 在我正确回忆 [卡片] 后,建议最优复习间隔。
24. 为我反复答错的卡片建一个'吸血鬼'识别: [粘贴]。
25. 把这些卡片从识别型改成回忆型: [粘贴]。
26. 建议怎么把 5 个相关事实合成一张更强的卡。
27. 找出这些卡片中太难、该拆分的: [粘贴]。
28. 构建一份年度复盘计划,让 [N] 张卡保持活力。
