# Tasks and Todos

26 prompts for breaking down work, prioritizing, and clearing the list.

## Breaking down

1. Break [project] into [N] tasks each under 30 minutes.
2. Identify the first concrete next action for [vague task].
3. Outline the dependency graph for [project] tasks: [paste].
4. Find tasks in [project] I could delegate or drop.
5. Break this goal [goal] into weekly milestones for [N] weeks.
6. Identify the 20% of tasks in [list] that drive 80% of value.
7. Convert this brainstorm into a prioritized backlog: [paste].
8. Generate sub-tasks for [task] including hidden prep work.

## Prioritizing

9. Rank [task list] by impact vs effort, surface top 3.
10. Apply Eisenhower matrix to these [N] tasks: [paste].
11. Identify which tasks must be done today vs deferrable: [paste].
12. Re-rank my todo list given new constraint: [constraint]. List: [paste].
13. Identify tasks that are urgent but not important from [list].
14. Suggest which 3 tasks to attempt before lunch tomorrow.
15. Apply RICE scoring to [list of initiatives].

## Clearing the list

16. Cull this todo list — flag tasks that have been there over [N] days.
17. Identify tasks I can batch together for efficiency: [paste].
18. Find tasks that became obsolete in my list: [paste].
19. Convert these vague todos into concrete actions: [paste].
20. Identify which tasks I should delegate and to whom: [paste + team].
21. Suggest a 'task triage' protocol I can run weekly.
22. Build a 'don't do' list from my last quarter's regrets.

## System building

23. Design a personal task management system using [tool].
24. Build a weekly review template that takes 30 minutes.
25. Suggest a tagging/labeling scheme for my todos by [dimension].
26. Create a project template I can reuse for similar work: [type].

**Total prompts: 26**

# 任务与待办

26 条 prompt: 拆解工作、排优先级、清单清空。

## 拆解

1. 把 [项目] 拆成 [N] 个任务,每个不超过 30 分钟。
2. 为 [模糊任务] 找出第一个具体的下一步动作。
3. 为 [项目] 的任务画出依赖图: [粘贴]。
4. 在 [项目] 中找出可以委派或砍掉的任务。
5. 把这个目标 [目标] 拆成 [N] 周的周里程碑。
6. 在 [清单] 中识别能驱动 80% 价值的 20% 任务。
7. 把这次头脑风暴转成有优先级的待办: [粘贴]。
8. 为 [任务] 生成子任务,包括隐藏的准备工作。

## 排优先级

9. 按影响 vs 投入对 [任务清单] 排序,选出前 3。
10. 对这 [N] 个任务应用艾森豪威尔矩阵: [粘贴]。
11. 判断哪些任务今天必须做,哪些可以推: [粘贴]。
12. 在新约束 [约束] 下重排我的待办: [清单]: [粘贴]。
13. 在 [清单] 中找出紧急但不重要的任务。
14. 建议明天午前尝试的 3 个任务。
15. 对 [一组行动] 应用 RICE 评分。

## 清空清单

16. 整理这份待办 — 标出在清单里待了超过 [N] 天的任务。
17. 找出可以批处理以提升效率的任务: [粘贴]。
18. 在我的清单中找出已过时的任务: [粘贴]。
19. 把这些模糊的待办转成具体动作: [粘贴]。
20. 找出该委派的任务和合适的对象: [粘贴 + 团队]。
21. 建议一个我可以每周跑一遍的任务分诊流程。
22. 基于上季度的遗憾建一份'不做清单'。

## 系统建设

23. 用 [工具] 设计一套个人任务管理系统。
24. 构建一份 30 分钟内能跑完的周度复盘模板。
25. 为我的待办按 [维度] 建议标签方案。
26. 为 [类型] 工作创建一个可复用的项目模板。
