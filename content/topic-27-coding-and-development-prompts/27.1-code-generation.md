# 代码生成

30 条 prompt: 从零生成各类代码。

## 函数与片段

1. 用 [语言] 写一个函数: 输入 [输入],返回 [输出]。
2. 用 [语言] 生成一个完成 [任务] 的工具函数,带类型注解和文档。
3. 用 [语言] 实现 [算法],复杂度 O(n)。
4. 用 [正则方言] 写一个匹配 [模式] 的正则,解释每个分组。
5. 用 [语言] 写脚本读 [文件格式],输出 [格式]。
6. 用 [语言] 写一个记录 [事件] 的装饰器/中间件。
7. 用 [语言] 实现一个带退避重试的包装器,作用于 [操作]。
8. 用 [语言][框架] 生成 CLI,带这些参数: [列表]。
9. 用 [语言] 写一个每天 [时间] 执行 [任务] 的 cron 脚本。
10. 用 [语言] 写一个函数,把 [输入] 校验对照 [schema]。

## API 与集成

11. 用 [语言] 写 [API] 客户端,含鉴权和错误处理。
12. 用 [框架] 为 [资源] 生成 RESTful CRUD 端点。
13. 在 [技术栈] 中为 [领域] 创建 GraphQL schema 和 resolver。
14. 用 [语言] 写一个 webhook 接收器,处理 [事件类型]。
